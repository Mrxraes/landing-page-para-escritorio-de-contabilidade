# landing-page-para-escritorio-de-contabilidade
anding page estática e responsiva para escritório de contabilidade, em HTML, CSS e JavaScript puros, sem dependências. Inclui hero com rotação de palavras, efeito 3D leve, animações de scroll com IntersectionObserver, carrossel, chat guiado e integração com WhatsApp (wa.me) com mensagem pré-formatada.
